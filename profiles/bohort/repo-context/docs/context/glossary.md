# Glossary

Terms that mean something specific here, and are ambiguous everywhere else.

| Term | Here it means |
| ---- | ------------- |
| **Document** | An invoice, a quote or a credit note. The three share a line structure and a total computation. |
| **Line** | One billable row: unit price, quantity. No tax on the line, tax is computed on the document. |
| **Net** | Before tax. **Gross** is after tax. We got this backwards for a month in 2025. |
| **Credit note** | A negative document. Same computation, the sign is applied by the caller. |
| **Issued** | The document has a number and can no longer be edited. Not the same as **sent**. |
| **Draft** | No number yet. Deletable. |
