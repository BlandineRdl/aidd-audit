## What the checklist did not catch

package says chunk. We kept `batchSize`: the option is public and two client
integrations already pass it, so a rename costs a breaking change for a word.
Noted here rather than fixed.
Nothing in the checklist covers naming consistency across packages, and probably
nothing should — that is what a second pair of eyes is for.
