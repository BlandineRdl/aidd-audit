# Boy Scout

Leave touched code slightly better than you found it.

- Improve only code the change touches.
- Fix nearby naming, duplication, dead code.
- Fix misleading comments and needless complexity.
- Only when the improvement is small.
- Only when the improvement is safe.
- Never expand into an unrelated refactor.
- Preserve behavior unless the feature changes it.
- Prefer removing complexity over adding abstraction.
- Note a larger cleanup separately.
- Never hide it inside this change.
